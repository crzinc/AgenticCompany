# Быстрый старт AgenticCompany

## Установка

1. Установите Python 3.8+
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Настройте переменные окружения:

```bash
cp .env.example .env
# Отредактируйте .env и добавьте ваши API ключи
```

## Запуск

```bash
python main.py
```

## Архитектура системы

### Агенты
- **ContentAgent**: Создание контента (блоги, посты, статьи)
- **AnalyticsAgent**: Анализ данных и рынков
- **TechnicalAgent**: Разработка и автоматизация
- **MarketingAgent**: Маркетинг и продвижение
- **FinanceAgent**: Финансовое управление

### Процесс работы
1. Генерация задач на основе потребностей
2. Распределение задач между агентами
3. Выполнение задач агентами
4. Сбор результатов и анализ эффективности

### Мониторинг
Система автоматически отслеживает:
- Количество выполненных задач
- Успешность агентов
- Прибыль от каждой задачи

## Расширение системы

### Добавление нового агента
1. Создайте новый файл в `src/agents/`
2. Унаследуйтесь от `BaseAgent`
3. Реализуйте методы `execute_task` и `can_handle_task`
4. Зарегистрируйте агента в `main.py`

### Интеграция с API
Добавьте реальные API для:
- Генерации контента (OpenAI, Anthropic)
- Анализа данных (Google Analytics, SEMrush)
- Маркетинга (Facebook Ads, Google Ads)
- Финансов (CoinGecko, Alpha Vantage)
